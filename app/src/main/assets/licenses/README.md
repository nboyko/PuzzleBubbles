# Bundled fonts

Fonts are bundled locally for offline use, unmodified under the SIL Open Font
License 1.1. Their copyright and license notices are packaged alongside this file.

| Font | Use | Source | License file |
| --- | --- | --- | --- |
| Lilita One Regular | Game-card titles | https://github.com/google/fonts/tree/main/ofl/lilitaone | `lilita_one_OFL.txt` |
| Baloo 2 (variable weight) | Home heading, welcome text, question, and hint | https://github.com/google/fonts/tree/main/ofl/baloo2 | `baloo_2_OFL.txt` |

Baloo 2 uses its native 400, 700, and 800 weight settings. Other app text keeps
the system sans-serif family.
